補充：PowerPoint 的投影片尺寸是以實際長度設定，而不是直接設定像素。這裡的 1920 × 1080 代表 16:9 的畫面比例；若需要輸出成 1920 × 1080 的圖片，還需要另外設定匯出解析度。
二、三種圖片排版模式
模式 A：高度優先、水平置中（預設）
圖片高度對齊投影片高度，保持原始比例，並水平置中。
排版規則：
- 圖片高度等於投影片高度。
- 圖片寬度依原始比例自動計算。
- 圖片水平置中。
- 圖片不變形。
- 超出左右邊界的部分由投影片視窗裁切。
適合：直式 PDF、文件頁面、講義等需要讓文字盡可能放大的內容。

模式 B：完整顯示、不裁切、置中
整張圖片完整放進投影片，保持比例，水平與垂直置中。
排版規則：
- 圖片不得超出投影片邊界。
- 保持原始長寬比例。
- 圖片水平置中。
- 圖片垂直置中。
- 空白區域使用白色背景填補。
適合：需要保留完整內容的文件、圖表、照片。
例如 A4 直式文件，會在投影片左右留下較多空白，但整頁內容都能看見。







模式 C：寬度優先、垂直置中
圖片寬度對齊投影片寬度，保持原始比例，並垂直置中。
排版規則：
- 圖片寬度等於投影片寬度。
- 圖片高度依原始比例自動計算。
- 圖片垂直置中。
- 圖片不變形。
- 超出上下邊界的部分由投影片視窗裁切。
適合：橫式文件、寬幅圖表、長條型圖片等。











三、三種模式的技術計算方式
假設：
- 投影片寬度：SW = 1920
- 投影片高度：SH = 1080
- 原始圖片寬度：IW
- 原始圖片高度：IH
模式 A：高度優先、水平置中
縮放倍率：
scale = SH / IH
圖片尺寸：
W = IW × scale
H = SH
圖片位置：
X = (SW - W) / 2
Y = 0
當 W > SW 時，左右部分超出投影片範圍。
模式 B：完整顯示、水平與垂直置中
縮放倍率：
scale = min(SW / IW, SH / IH)
圖片尺寸：
W = IW × scale
H = IH × scale
圖片位置：
X = (SW - W) / 2
Y = (SH - H) / 2
這個模式能確保整張圖片完整顯示。
模式 C：寬度優先、垂直置中
縮放倍率：
scale = SW / IW
圖片尺寸：
W = SW
H = IH × scale
圖片位置：
X = 0
Y = (SH - H) / 2
當 H > SH 時，上下部分超出投影片範圍。

一個實作上的重要細節
在 PowerPoint 中，超出投影片邊界的圖片通常會在投影片播放或匯出時被視窗裁切。因此，模式 A 與模式 C 不需要真的把圖片裁切成另一張圖片，只要將原始圖片等比例放大，並設定正確的位置即可。
這樣做的優點是：
- 不必額外產生裁切後的圖片。
- 保留原始圖片品質。
- 三種模式可以共用同一套 PPT 產生模組。
- 減少中間檔案及記憶體使用。
